## About

This Repository contains my research about the new HTJ2K Compression method that recently got added to OpenEXR.
The script is used to test the de-/compression speed and file size of all lossless OpenEXR compression methods.

I am doing this research as my Grad Work @ [Howest](https://www.howest.be/en) - [DAE](https://www.digitalartsandentertainment.be/)
